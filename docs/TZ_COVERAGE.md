## 12. Критерии приёмки MVP

Все критерии требуют эталонного набора из 20–30 размеченных тендеров. Набора нет, поэтому **ни один критерий не измерен**. Демо-лот (31 требование, 2 заявки) — это смоук-тест, а не эталон.

| Критерий | Статус | Как будет измеряться (Этап 1) |
|---|---|---|
| Recall обязательных требований 100% | ⏳ | сравнение `requirements` с разметкой эксперта |
| Точность статусов 100% (без review), доля review ≤ 15% | ⏳ | матрица ошибок `Match.status` против эталона |
| 0 ложных «Соответствует» по невыполненным обязательным | ⏳ | отдельная метрика, блокирующая выпуск |
| 100% пунктов с рабочей ссылкой на страницу | 🟡 | `quoteVerified`; можно считать автоматически уже сейчас |
| 100 страниц ≤ 10 мин | ⏳ | замер по журналу прогонов |
| Рекомендации применимы в ≥ 80% случаев | ⏳ | экспертная оценка |
